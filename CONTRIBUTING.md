# Contributing

Thank you for your interest. **Outside contributions aren't accepted yet**: Chainpen is new, and how contributed code would be owned and licensed hasn't been settled (see [LICENSE](LICENSE)).

You're welcome to:

- report bugs and suggest features in GitHub Issues once the repository is public (the beta). Each kind of issue has a short form: something that doesn't work, a PDF that doesn't open or look right, an idea, or a crash report (Chainpen fills that one in). Issues are public, so please don't attach your own filled-in documents;
- report security problems privately, as [SECURITY.md](SECURITY.md) describes;
- read, build, change and share the code under the [licence](LICENSE): free for everyone to use, but not to sell.

Pull requests from outside the project are closed automatically, with a pointer to issues (`.github/workflows/outside-pull-requests.yml`). When contributions open, delete that workflow and the pull request template; contributions will need a contributor licence agreement (CLA), so the project can keep licensing the whole of Chainpen as one work.

Building and testing are described in the [README](README.md); how the editable working copy is stored is in [docs/FILE-FORMAT.md](docs/FILE-FORMAT.md).
