# Contributing

Thank you for your interest. **Outside contributions aren't accepted yet** (decision FS-009 in [docs/PLAN.md](docs/PLAN.md)): the project's ownership and licensing are still being set up for a possible paid edition, and accepting code now would complicate that.

You're welcome to:

- report bugs and suggest features in GitHub Issues once the repository is public (the beta). Each kind of issue has a short form: something that doesn't work, a PDF that doesn't open or look right, an idea, or a crash report (Fillsign fills that one in). Issues are public, so please don't attach your own filled-in documents;
- report security problems privately, as [SECURITY.md](SECURITY.md) describes;
- read, build and change the code under the [Business Source License](LICENSE): free for personal use, and for everyone during the beta.

Pull requests from outside the project are closed automatically, with a pointer to issues (`.github/workflows/outside-pull-requests.yml`). When contributions open, delete that workflow and the pull request template; contributions will need a contributor licence agreement (CLA), so contributed code can be offered under the paid business licence too.

Building and testing are described in the [README](README.md); how the editable working copy is stored is in [docs/FILE-FORMAT.md](docs/FILE-FORMAT.md).
