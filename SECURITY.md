# Security

Please report security problems privately, not in a public issue: use
[Report a vulnerability](https://github.com/fillsign/fillsign/security/advisories/new) on the repository's
Security tab. Say what you found, which version, and how to reproduce it; a PDF that shows the problem is welcome there,
since private reports aren't public.

Only the latest release gets security fixes. Fillsign works offline: apart from checking for updates, it doesn't send
anything anywhere, and crash reports are only sent if you choose to send them yourself.
